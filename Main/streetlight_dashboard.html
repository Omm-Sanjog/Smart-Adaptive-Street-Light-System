📁 LOCAL CSV LOGGER — SETUP GUIDE
Writes data directly to your laptop · Zero browser limitations
STEP 1 — INSTALL PYTHON DEPENDENCY
pip install pyserial
STEP 2 — RUN THE LOGGER
python logger.py
Place logger.py in the same folder as this HTML file. Run it in a terminal/CMD window. Keep it running while you use the dashboard.
STEP 3 — SELECT YOUR PORT
The script will list all available COM ports and let you pick one. Select the receiver ESP32 (the one connected via USB). Use the same baud rate as set in the dashboard (default: 115200).
WHAT IT DOES
✔ Reads every raw line from the serial port
✔ Parses ID:SL-01,Loc:...,N:,M:,B:,V:,I:,P: packets
✔ Accumulates energy (kWh) per node using time deltas
✔ Writes a new timestamped CSV file on every run
✔ Flushes to disk after every single packet — no data loss on crash
✔ Prints a live summary line per packet in the terminal
OUTPUT FILE
streetlight_2026-04-11_08-26-00.csv
Saved in the same folder as logger.py. A new file is created each time you start the logger.
CSV COLUMNS
timestamp · node_id · location · night · motion · brightness_pct · voltage_V · current_A · power_W · energy_kWh · rssi
⚠ NOTE: The dashboard and logger.py both read the same serial port. You should only open one at a time — either use the dashboard's Web Serial connection OR run logger.py, not both simultaneously on the same port.
