📁 LOCAL CSV LOGGER — SETUP GUIDE
Writes data directly to your laptop · Zero browser limitations
Step 1 — Install Python Dependency
pip install pyserial websockets
Step 2 — Run the Logger
python logger.py
Place logger.py in the same folder as this HTML file. Keep it running while using the dashboard.
Step 3 — Select your Port
The script will list available COM ports. Select the receiver ESP32. Use the same baud rate as in the dashboard (default: 115200).
What It Does
✔ Reads every raw line from the serial port
✔ Parses ID:SL-01,Loc:...,N:,M:,B:,V:,I:,P: packets
✔ Accumulates energy (kWh) per node using time deltas
✔ Writes a timestamped CSV file on every run
✔ Flushes to disk after every single packet
CSV Columns
timestamp · node_id · location · night · motion · brightness_pct · voltage_V · current_A · power_W · energy_kWh · rssi
⚠ NOTE: The dashboard and logger.py both read the same serial port. Use only one at a time — either the dashboard's Web Serial connection OR logger.py, not both simultaneously.
